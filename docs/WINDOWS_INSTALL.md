# تثبيت تطبيق MEAAF على Windows

> هذه الحزمة تثبّت واجهة Windows الحالية (WPF) فقط. قاعدة SQL Server وخدماتها لا تُثبَّت مع التطبيق، والنسخة ما زالت غير معتمدة للإنتاج.

## ما يلزم

- Windows 10/11 ‏64-bit.
- خادم SQL Server 2019 أو أحدث يمكن لجهاز المستخدم الوصول إليه.
- لتشغيل المثبّت: لا يلزم تثبيت .NET منفصلاً؛ حزمة النشر المخصصة لـ`win-x64` تتضمن Runtime .NET/WPF.
- لإنشاء المثبّت من المصدر: Windows، و.NET 8 SDK، وInno Setup 6.

## تجهيز قاعدة البيانات

1. نفّذ ملفات `db` المرفقة بالترتيب `001` إلى `005` على SQL Server؛ ينشئ `001_schema.sql` قاعدة `MEAAF_DB` تلقائياً إن لم تكن موجودة. هذه الخطوات تنفذها جهة مسؤولة عن قاعدة البيانات، ولا يقوم المثبّت بتنفيذ SQL أو طلب صلاحيات SQL.
2. هذا المخطط البديل مخصص لقاعدة جديدة. لا تستخدم `001_schema.sql` كترقية لقاعدة قائمة من المخطط السابق؛ خذ نسخة احتياطية وأنشئ خطة تحويل بيانات منفصلة. الملفان `004` و`005` محجوزان ولا ينفذان ترقية في الإصدار الحالي.
3. امنح هوية Windows التي ستشغل التطبيق صلاحيات قاعدة البيانات اللازمة بحسب سياسة المؤسسة. استخدم مصادقة Windows وTLS موثوقاً حيثما أمكن.

## إعداد اتصال التطبيق

يقرأ التطبيق `MEAAF_CONNECTION_STRING` من متغيرات البيئة أولاً (لإعدادات مسؤول النظام أو المصادقة المتقدمة). إذا لم يوجد، يستخدم إعداد الخادم المحفوظ لهذا المستخدم؛ وعند تعذر الاتصال تظهر شاشة لاختيار الخادم وقاعدة البيانات واختبار الاتصال. تحفظ الشاشة اسم الخادم وقاعدة البيانات فقط في `%LocalAppData%\MEAAF\connection.json`، وتستخدم مصادقة Windows ولا تحفظ كلمات مرور. عند عدم وجود إعداد محفوظ يبدأ من إعداد `MEAAF.exe.config` (افتراضياً `localhost` و`MEAAF_DB`).

```powershell
[Environment]::SetEnvironmentVariable(
  'MEAAF_CONNECTION_STRING',
  'Server=sqlserver;Database=MEAAF_DB;Integrated Security=True;Encrypt=True;TrustServerCertificate=False;',
  'User'
)
```

استبدل `sqlserver` باسم خادمك. لا تضع كلمة مرور SQL صريحة في ملف الإعدادات أو في سجل الأوامر. يجب أن يثق Windows بشهادة TLS الخاصة بالخادم.

## التثبيت والتشغيل

1. شغّل `MEAAF-Setup-0.1.0-win-x64.exe` وثبّت التطبيق للمستخدم الحالي.
2. شغّل MEAAF من قائمة Start. على قاعدة جديدة، تظهر شاشة إنشاء كلمة مرور المدير الأول؛ استخدم 12 حرفاً على الأقل. لا تُحفظ كلمة المرور في ملفات التطبيق، وتُخزن بعد التجزئة.
3. سجّل الدخول باسم المستخدم `admin` وكلمة المرور التي أنشأتها.
4. أنشئ نسخة احتياطية واختبر الاستعادة، واختبر الصلاحيات والعزل على قاعدة غير إنتاجية قبل أي استخدام فعلي.

في أتمتة النشر يمكن توفير `MEAAF_INITIAL_ADMIN_PASSWORD` قبل أول تشغيل بدلاً من شاشة الإعداد. لا تجعل هذا المتغير عاماً على أجهزة متعددة ولا تسجله في سجلات النشر.

## إنشاء الحزمة من المصدر

على جهاز Windows:

```powershell
.\installer\Build-Windows-Installer.ps1
```

يتحقق السكربت من الاختبارات أولاً، ثم ينشر نسخة self-contained لـ`win-x64` ويجمع المثبّت عبر Inno Setup 6. الناتج:

```text
artifacts\installer\MEAAF-Setup-0.1.0-win-x64.exe
```

لإنشاء النشر دون تشغيل الاختبارات (غير موصى به للتوزيع):

```powershell
.\installer\Build-Windows-Installer.ps1 -SkipTests
```

يمكن تشغيل سير العمل `.github/workflows/windows-installer.yml` على GitHub لبناء الحزمة بعد دفع التغييرات؛ يرفع ملفاً غير موقّع باسم `MEAAF-Setup-win-x64` لمدة 14 يوماً. الحزمة الحالية غير موقّعة رقمياً. وقّع المثبّت وملفات التطبيق وفق سياسة النشر واختبر التثبيت والترقية والإزالة على جهاز Windows نظيف قبل التوزيع. إزالة التطبيق لا تحذف قاعدة SQL Server.
