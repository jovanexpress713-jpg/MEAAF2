# مراجعة الإنتاج — 2026-10-06

## ما عُثر عليه وعولج في هذه المراجعة

- كانت الشيفرة موجودة فقط داخل `MEAAF_FULL_COMPLETE.zip`؛ فُكّت إلى بنية مصدر قابلة للمراجعة في جذر المستودع، وأُعيدت تعبئة الأرشيف ليحتوي النسخة المحدثة.
- أُصلحت توقيعات tuple غير الصالحة في عقد الموصل، ومسارات المشاريع ذات الفواصل المكررة في ملف الحل.
- أُضيفت المراجع الناقصة إلى بعض ملفات WPF، وأُضيف تمكين استهداف Windows عند البناء من بيئة غير Windows.
- أُضيف فحص `DemandTenant` لكل خدمات الأعمال، وربط البحث والتحديثات بمعرّف المنشأة، وتقوية صلاحيات RBAC وربط المستخدم بالدور في المنشأة نفسها.
- أُضيفت مفاتيح أجنبية مركبة لمنع ربط فاتورة بمريض من منشأة أخرى، وقيود تحقق للمبالغ وبنود القيود.
- أصبح إنشاء الفاتورة والقيد المحاسبي المسودة وسجل التدقيق في معاملة SQL واحدة. أُضيف مسار اعتماد للقيد، وأصبحت مؤشرات المدين/الدائن تستبعد المسودات.
- أُكملت واجهة المخزون الأساسية، وأُضيف staging محدود للترحيل ومسار مرضى فقط لربط الحقول والتحقق من المدخلات والتكرارات وعرض أول 100 خطأ صف. الاستيراد ذري ومدقق؛ تُحفظ بصمة SHA-256 للخريطة والصفوف لمنع اعتماد staging تغيّر بعد التحقق، ثم تُحذف صفوف staging بعد نجاح الاستيراد. أضيف إجراء يدوي ومدقق لحذف صفوف التحقق الفاشلة بعد 30 يوماً مع إبقاء سجل المهمة.
- أُصلحت عمليات التحقق من أسماء الجداول في موصل SQL Server، بما في ذلك `CountTable`، وأُضيف حد أعلى لعدد الصفوف المقروءة.
- أُزيل السلوك المضلل من خدمة المزامنة: لم تعد تضع العناصر في حالة `Pushed` دون إرسالها؛ التنفيذ يرفض العمل حتى إعداد النقل الفعلي.
- أُزيلت كلمة المرور الافتراضية الثابتة للمدير الأول؛ تظهر شاشة إنشاء أول مدير عند التهيئة، مع دعم `MEAAF_INITIAL_ADMIN_PASSWORD` للنشر المؤتمت، والتحقق من 12 حرفاً و72 بايت UTF-8 كحد أعلى. أُضيف تغيير كلمة المرور الحالية من الواجهة مع التحقق من القديمة والتدقيق ضمن معاملة.
- جُهز مشروع WPF باسم وإصدار تطبيق واضحين، وشاشة إعداد اتصال Windows Authentication تحفظ اسم الخادم/قاعدة البيانات فقط، وشاشة إعداد أول مدير، وسكربت نشر self-contained لـWindows x64 ومشروع Inno Setup مع دليل تثبيت وسير عمل CI. لم يُبنَ المثبّت أو يُشغّل سير CI فعلياً في هذه البيئة.
- أُضيف تحقق هيكلي آلي لـ XML، ومسارات المشاريع، وروابط أحداث XAML، واختبارات وحدات إضافية لقواعد القيود.

## ما لا يزال غير مكتمل / غير متحقق

- لم يتوفر `dotnet` أو MSBuild أو SQL Server أو Windows/Inno Setup في بيئة المراجعة. لذلك لم يُنفّذ `dotnet restore/build/test`، ولم تُنشأ حزمة Windows الفعلية، ولا أي اختبار تكامل لقاعدة البيانات. أُضيفت فقط وصفة نشر self-contained ومشروع Inno Setup؛ فحص Python الهيكلي لا يثبت أن C# يترجم.
- الترحيل النهائي متاح للمرضى فقط ولا يزال غير مختبر على SQL Server. لا توجد خرائط أو تسوية أو استيراد نهائي لبقية الكيانات، ولا توجد مطابقة سجلات أو آلية تراجع بعد نجاح الاستيراد. تنظيف بيانات التحقق الفاشلة يدوي فقط بعد 30 يوماً، ولا توجد مهمة مجدولة لتنظيف بقية حالات staging.
- المزامنة الفعلية غير موجودة؛ لا يوجد endpoint أو transport أو حل تعارض. كما أن SQLite لا يزال مخزناً محلياً أولياً غير مربوط بالخدمات.
- الرخصة ليست جزءاً من تسجيل الدخول أو الترخيص التشغيلي، ولا يوجد خادم تفعيل.
- النسخ الاحتياطي يتعامل مع قاعدة SQL كاملة، وليس نسخة معزولة لكل tenant. يجب قصر صلاحياته على مشغل المنصة واختبار العزل قبل تشغيل متعدد المنشآت.
- لا توجد إدارة مكتملة للمستخدمين/الأدوار أو إعادة تعيين كلمة المرور، ولا سجل مخزون تفصيلي أو دورة مدفوعات/مرتجعات.
- يلزم اختبار تثبيت جديد وترقية قاعدة قائمة، وعزل tenant باختبارات فعلية، واختبار RBAC شامل، واختبار استعادة، واختبارات واجهة واختراق.
